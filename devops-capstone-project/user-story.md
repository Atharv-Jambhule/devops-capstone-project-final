# User Story Template

**Title:** [Short action-oriented title]

**As a** [type of user],  
**I want** [an action or capability],  
**So that** [benefit or outcome].

## Acceptance Criteria
- [ ] Given [context], when [action], then [expected result].
- [ ] Invalid input is handled with a useful error response.
- [ ] Automated tests cover the expected behavior.

## Definition of Done
- [ ] Implementation is complete.
- [ ] Unit tests pass.
- [ ] Lint checks pass.
- [ ] Documentation is updated.
- [ ] Changes are reviewed and merged.
