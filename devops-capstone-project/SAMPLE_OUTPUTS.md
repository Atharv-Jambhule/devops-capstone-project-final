# Sample Outputs — Not Execution Evidence

Any terminal outputs, Docker image IDs, Kubernetes pod names, timestamps, test counts, and pipeline statuses shown in task examples are illustrative. They are not generated by your actual machine or cluster.

Generate real evidence by running:
- `nosetests`
- `docker images`
- `kubectl get deployments,pods,replicasets,services`
- `tkn pipelinerun logs <run-name>`

Do not submit sample values as proof of a successful build, deployment, or pipeline run.
